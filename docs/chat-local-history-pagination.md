# 本地聊天历史分页

好友和已保存正文的群聊共用本地历史展开方式：初始展示最近 320 条；有更早的本地记录时，点击「加载更早的本地消息」，每次多展开 320 条。展开后保持原来的阅读位置。

这项优化只影响聊天页的展示范围。消息采集、白名单存储和 MCP 读取仍使用完整的本地快照；`read_chat` 的 `limit` 和 `before` 分页与界面展开相互独立。

展开本地消息时不请求抖音。在本地历史全部展开后，群聊可通过「从抖音补读历史」显式请求远程历史；补读结果与本地消息合并。

构建 Web 后运行 `node scripts/check-group-chat-ui.mjs`，其中的 400 条合成群消息用于验证本地展开、远程补读和已有内容保留。可用 `DY2_CHROMIUM` 指定 Chromium 可执行文件。
